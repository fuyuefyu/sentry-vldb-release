# SENTRY VLDB Release Packages

This repository contains the release archives for the SENTRY VLDB submission.
The archives are kept as uploaded review artifacts: unpack them before running
the commands below.

## Archives

- `packages/SENTRY_VLDB_artifact.zip` contains the scripts, shipped summary
  artifacts, provenance sources, manifests, generated tables, and plotting code
  used to reproduce every numeric dataset shown in the six RQ figures.
- `packages/SENTRY_VLDB_compile_package_20260802_021120.zip` contains the
  compile-ready manuscript bundle, including `main.pdf`, LaTeX source,
  bibliography files, local class/style files, generated table source, and the
  six paper figures.
- `packages/SENTRY_executable_validation_code_package_20260802_021120.zip`
  contains the standalone DuckDB-backed executable validation package used for
  the database/operator witness row in the certificate-disclosure table.
- `packages/SENTRY_VLDB_artifact.zip.sha256` is the SHA-256 sidecar for the
  artifact archive. Full archive hashes are listed in `checksums.sha256`.

## Quick Start

Verify the archive hashes:

```bash
sha256sum -c checksums.sha256
```

Rebuild all paper figure datasets and figure files:

```bash
unzip packages/SENTRY_VLDB_artifact.zip -d sentry-vldb-artifact
cd sentry-vldb-artifact
python -m pip install -r requirements.txt
bash run_all.sh
```

Compile the manuscript:

```bash
unzip packages/SENTRY_VLDB_compile_package_20260802_021120.zip -d sentry-vldb-compile
cd sentry-vldb-compile
make pdf
```

Run the executable validation package:

```bash
unzip packages/SENTRY_executable_validation_code_package_20260802_021120.zip
cd sentry-executable-validation
python -m pip install -e .
python -m pytest -q
python -m sentry_validation.cli all --config configs/smoke.yaml
```

Use `configs/validation.yaml` instead of `configs/smoke.yaml` for the full
standalone validation run.

## Source Boundaries

The artifact archive includes the shipped summary tables under
`artifacts/vldb/` and the scripts that transform those tables into the exact
figure datasets under `results/`. It also includes upstream summary-builder
source provenance:

- `provenance/summary_builders/run_vldb_24h.py` for workload, baseline,
  calibration, metadata, DB-scale, and diagnostic summaries;
- `provenance/summary_builders/run_optimizer_validation_artifacts.py` for
  optimizer column-generation and validation-LP summaries;
- `provenance/summary_builders/run_db_operator_grid.py` for the DuckDB operator
  grid;
- `provenance/prior_nips_artifact/` for the prior recommender-audit source
  lineage.

MovieLens-1M, MIND-small, Amazon Reviews 2023, and KuaiRand raw corpora are not
redistributed in this repository. The default artifact rebuild is therefore a
deterministic summary-level reproduction from shipped source summaries, while
the provenance scripts document the heavier upstream summary-generation path.
